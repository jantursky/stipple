# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussions about the work. Harassment and personal attacks aren't tolerated in issues, pull requests or any other project space.

Report unacceptable behavior to jan.tursky@gmail.com. Reports are handled confidentially.
