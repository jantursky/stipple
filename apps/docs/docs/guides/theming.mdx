A `StippleTheme` has five parts:

| Part | Meaning |
| --- | --- |
| `ink` | The colour of a filled cell. |
| `paper` | The colour of an empty cell. |
| `palette` | Optional colours from paper to ink. With three or more, a tone picks a position on the ramp and the pattern decides between the two colours around it. |
| `cell` | Cell size in dp. Whole pixels are used, so neighbouring cells never leave seams. Default 3 dp. |
| `shape` | `CellShape.Square` or `CellShape.Dot`. |

`StippleTheme.Light` and `StippleTheme.Dark` are the defaults. `copy` changes one part.

```kotlin
val sunset = StippleTheme.Light.copy(
    palette = listOf(Color(0xFF14122B), Color(0xFF6B5B95), Color(0xFFEC003F), Color(0xFFFFB900), Color(0xFFFFF8E5)),
)
```

## Provide it once

`ProvideStippleTheme` puts a theme in a composition local. Every dither below it uses that theme unless the call passes its own `theme`.

```kotlin
ProvideStippleTheme(StippleTheme.Light.copy(cell = 2.dp)) {
    Screen()
}
```

Without an argument, `ProvideStippleTheme()` follows the system's light or dark mode through `systemStippleTheme()`.

## Presets and gradients

`StippleTheme.presets` maps readable names to ready-made looks, inspired by old screens and print: `GameBoy` (four greens), `Cga` (white, cyan, magenta, black), `Newsprint` (warm paper, round dots), `Macintosh` (black on white, coarse grain) and `Amber` (phosphor ink on a dark screen). Each is also a member of `StippleTheme`, so `StippleTheme.GameBoy` works directly.

`StippleTheme.gradient(paper, ink, steps = 4)` builds a theme whose palette blends evenly from paper to ink in 2 to 8 colours (the most the shader draws), blended per channel in sRGB:

```kotlin
val ramp = StippleTheme.gradient(Color.White, Color(0xFF0B3D91), steps = 5, cell = 2.dp)
```

## Contrast

A dither shows less than full ink, so what a viewer sees has lower contrast than `ink` against `paper`. `theme.contrastRatio` gives the WCAG ratio of the two colours: aim for 4.5 for text and 3 for graphics. `theme.ensureContrast(minContrast = 4.5f)` returns the same theme when it is already readable and otherwise a copy with black or white ink (whichever contrasts more with the paper) and no palette. `DitherText` calls it for you.
